# Scripts shipped in the worker image (Dockerfile.worker), relative to scripts/.
#
# Audit G2-05: the worker image is production, and production is the real
# clinic. It used to carry the whole scripts/ folder minus a denylist, so every
# new demo seed or test fixture landed on the server until someone remembered
# to exclude it. Now only what is listed here is copied; anything else stays
# out by default. The build fails if a listed file is missing.
#
# Only operational tools belong here: production data fixes (DRY RUN by
# default, APPLY=1 writes), encryption backfills, catalog imports, bot and
# account setup, read-only reports, and the helpers they import. Never a demo
# or test seed, never a script that goes through scripts/_destructive-guard.ts.
# tests/unit/seed-guard.test.ts checks both, and that every fix-*/backfill-*
# script is either listed or explicitly dev-only.
